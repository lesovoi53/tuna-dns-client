# TUNA DNS Client для Windows

[Скачать Windows x64](https://github.com/lesovoi53/tuna-dns-client/releases/latest) · [Изменения](CHANGELOG.md) · [Результаты проверок](VALIDATION.md)

Клиент на Go с интерфейсом WebView2 для [TUNA DNS Tunnel](https://github.com/lesovoi53/tuna-dns-tunnel) и совместимых StormDNS/MasterDnsVPN-серверов. Windows 10/11 x64, Microsoft Edge WebView2 Runtime. Права администратора не нужны. Это локальный SOCKS5-клиент: системные маршруты и настройки прокси Windows он не меняет.

## Как пользоваться

1. Запустите `TUNA-DNS-Client-0.1.2.exe`, импортируйте `tuna://` или `stormdns://`.
2. В «DNS-резолверы» выберите домен. Используйте адреса профиля, введите свои или скачайте текстовую HTTPS-базу. По умолчанию указан список резолверов проекта MassDNS на GitHub; адрес можно заменить.
3. Выберите число параллельных проверок (1–128) и запустите проверку. Прогресс показывает число завершённых проверок, общий объём и процент. Затем выберите рабочие адреса и сохраните. Каждый домен одного сервера хранит свой набор. «Из профиля» возвращает исходный набор. Скорость не измеряется и рейтинг не строится: ядро проверяет реальные ответы DNS-туннеля и допустимый MTU.
4. Нажмите «Подключить». Блок «Ход подключения» показывает текущий этап, длительность ожидания, прогресс проверки резолверов, попытки установки сессии и события ядра. По умолчанию SOCKS5 доступен на `127.0.0.1:10808`. Кнопка «Проверить соединение» запрашивает HTTPS через этот SOCKS с проверкой сертификата; прямого обхода при ошибке нет.
5. Укажите SOCKS5 в другом приложении либо скопируйте/скачайте outbound или полную конфигурацию из раздела экспорта. При закрытии TUNA DNS Client туннель завершается.

Полная конфигурация sing-box/Xray создаёт отдельный локальный вход на 10809 (10810, если 10809 занят самим TUNA). Другие процессы могут занимать этот порт: при необходимости измените его в экспортированном JSON. Конфигурации соответствуют SOCKS outbound [sing-box](https://sing-box.sagernet.org/configuration/outbound/socks/) и [Xray](https://xtls.github.io/en/config/outbounds/socks.html); туннель не становится встроенным транспортом этих ядер.

Если другой VPN-клиент работает в режиме TUN, добавьте исключение для `%APPDATA%\TUNA DNS Client\tuna-dns-core.exe` (или прямые маршруты к используемым резолверам). Иначе его перехват может замкнуть DNS-туннель через самого себя. Экспортируемые минимальные конфигурации TUN не включают. Локальный SOCKS не требует пароля и доступен другим процессам на этом компьютере.

## Хранение и ограничения

Профили сохраняются в `%APPDATA%\TUNA DNS Client\profiles.dpapi`, зашифрованные Windows DPAPI для текущего пользователя. Папка доступна текущему пользователю и SYSTEM. Временная конфигурация с ключом передаётся ядру через приватные файлы, удаляется после остановки; оставшиеся после аварии файлы очищаются при следующем запуске. Ключи не попадают в журнал и аргументы процессов. Не переносите `profiles.dpapi` на другой компьютер: используйте исходные ссылки.

Поддерживаются до 100 профилей и до 16 доменов одного сервера; отдельные VPN-серверы не объединяются в группу. Сканирование допускает до 100000 кандидатов, проверяет пакетами по выбранному числу потоков (1–128, по умолчанию 32), максимум 30 минут за запуск. Частичные результаты остаются доступны после остановки. Набор профиля/выбора ограничен 128 адресами. Загрузка базы идёт обычным HTTPS через сетевые настройки Windows, отдельно от проверки туннеля. Импорт и изменение параметров доступны при остановленном подключении и сканировании.

Сборка для ручной проверки не подписана Authenticode. Приложение использует [go-webview2](https://github.com/jchv/go-webview2), транспорт — закреплённый MasterDnsVPN; происхождение и лицензии в `native/PROVENANCE.md`. Длительное тестирование, IPv6-сеть, UDP-приложения и совместная работа со сторонними TUN-клиентами пока не подтверждены. Выполненные проверки описаны в `VALIDATION.md`.

## Сборка

Требуется Go 1.26.3 или новее и PowerShell. Скрипт скачивает закреплённый архив MasterDnsVPN и проверяет SHA256; подробности в `native/PROVENANCE.md`. Можно указать путь к Go параметром `-GoExe`.

```powershell
./scripts/build-core.ps1
./scripts/build.ps1
```

`scripts/build.ps1` запускает тесты и собирает EXE/ZIP в `dist`. Тесты DPAPI выполняйте под обычной учётной записью Windows с загруженным профилем: изолированная учётная запись без профиля не предоставляет DPAPI. Диагностический режим `--serve --listen 127.0.0.1:8770 --data-dir <папка>` выдаёт локальную ссылку с токеном; не передавайте её другим пользователям. Рабочий интерфейс использует тот же Go API, что и окно WebView2.

# Проверка Windows-клиента — 23 октября 2026

## Обновление 0.1.2

На главном экране показаны этап подключения, прошедшее время, прогресс MTU/резолверов, номер попытки установки сессии и последние события ядра. Отображаются неуспешная проверка, ожидание повторной попытки и сброс сессии. Зелёный индикатор и HTTPS-проверка доступны только после готовности SOCKS5. Секреты и необработанные строки ядра в интерфейс не передаются. Добавлен тест последовательности этапов, повторных попыток, восстановления и фильтрации секретов.

## Обновление 0.1.1

Добавлен реальный прогресс сканирования: завершённые проверки / общее количество, процент и полоса прогресса. Нативный счётчик обновляется после завершения каждой проверки, а не при постановке адреса в очередь. Отмена не превращает оставшиеся адреса в завершённые. Настройка параллелизма 1–128 сохраняется между запусками, по умолчанию 32; для сканера отключено автоматическое повышение выбранного числа воркеров. Параметры самого подключения не меняются.

Добавлен интеграционный тест ограничений параллелизма, монотонности прогресса и завершения двух отрицательных проверок с одним воркером, а также сохранения выбора. Предыдущая сборка и открытое пользователем окно не заменяются: EXE обновления имеет отдельное имя.

- Go 1.26.3, Windows amd64; нативное ядро MasterDnsVPN закреплено на `7de2476f1c33e69eec35360c52810dab43c5c986`.
- Финальный EXE создал настоящее отвечающее окно WebView2 «TUNA DNS Client»; штатное закрытие окна проверено. `go test ./...` и `go vet ./...` завершились успешно.
- 9 тестов профилей: форматы TUNA/StormDNS, несколько доменов, повреждённое сжатие, ограничения размера, настройки, независимые наборы резолверов, TOML и экспорт.
- 8 интеграционных тестов: Windows DPAPI и отказ при повреждении данных; сохранение/восстановление настроек; реальный core.exe `-validate` с двумя доменами и стратегией 5; SOCKS с удалённым разрешением имени, отказ без Direct, повреждённый ответ, проверка TLS, занятый порт.
- Тесты адаптера и конфигурации upstream проходят. Отрицательное сканирование подтверждает, что ядро проверяет только выбранные пары домен/резолвер.
- Завершённая проверка без рабочих резолверов отличается от тайм-аута/отмены: первая позволяет продолжить следующий пакет, вторые показывают неполный результат. Отдельные нативные тесты покрывают отрицательный UDP-ответ, отмену и пустой ввод.
- На разрешённой VPS (адрес исключён из публичного отчёта) без изменения её настроек: импорт текущего четырёхдоменного профиля; отдельная нативная проверка каждого домена через адрес этой VPS как резолвер; все четыре дали рабочий ответ. Подключение через Windows-ядро, HTTPS Cloudflare через SOCKS5 с проверкой сертификата — успешно, 4,4 секунды в контрольном запросе. Отключение прошло. Ключи и ссылки не включены в отчёт.
- Полные конфигурации sing-box и Xray сгенерированы и разобраны как JSON; схемы SOCKS сверены с официальной документацией/исходниками. Проверен непересекающийся локальный входной порт.
- Интерфейс A проверен на работающем локальном API: пустое состояние и импортированный профиль отображают четыре отдельных домена. DOM-проверки сохраняют черновики при обновлении статуса, выбирают 50 рабочих результатов без ограничения в три адреса, исключают нерабочие результаты и отправляют верный домен.
- Реальная HTTPS-загрузка базы MassDNS через приложение: получено 8477 адресов. Первоначальный источник public-dns.info завершился тайм-аутом, поэтому по умолчанию установлен проверенный GitHub-источник MassDNS; пользователь может изменить URL.

## Границы проверки

Проверка VPS использовала прямой DNS endpoint `адрес VPS:53`, поэтому она не доказывает доступность каждого домена через публичные рекурсивные DNS из сети пользователя. Именно для такой проверки предусмотрено сканирование в приложении. Здесь нет замера скорости или обещания прироста от нескольких доменов.

Отдельный запуск сторонних sing-box/Xray с этими файлами, совместный TUN, Windows на другом ПК, IPv6-сеть, UDP-приложения и многочасовая сессия не проверялись. Это первая сборка для ручной проверки. DPAPI требует загруженного профиля Windows; тесты успешно выполнены вне изолированной служебной учётной записи Codex.

Локальный SOCKS5
—
Адрес слушает только loopback этого компьютера. Доступ к нему могут получить другие локальные процессы. Не публикуйте этот порт в сеть.


Конфигурация другого клиента
Экспорт направляет трафик в SOCKS5 TUNA DNS Client. Сам DNS-туннель продолжает обслуживать запущенное ядро TUNA; его нельзя останавливать во время использования экспортированной конфигурации.


Параметры профиля
Параметры ядра · JSON
Поля в исходном формате: MTU, ARQ, дублирование, сжатие, рабочие потоки и интервалы. Ключи используют snake_case. Ключ и метод шифрования должны совпадать с сервером.
Во время подключения и сканирования параметры недоступны. Сначала завершите текущую операцию.
